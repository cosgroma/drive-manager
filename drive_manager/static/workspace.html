What this evidence covers

Preserve before consolidating

Git history snapshots retain named refs and HEAD, then restore into an empty repository and pass Git integrity checks. Original workspaces stay in place. Working files, ignored data, LFS payloads, reflogs, configuration and submodule repositories still need separate preservation before retirement.

Missing registry entries

These decisions change only workspace metadata. Recovery records are retained; no files or Git branches are removed.

Archival relocations

Same-volume moves preserve the whole tree and keep the legacy path working through a compatibility junction. They reclaim no space.

Snapshot comparisons

Compare completed manifest points in time. Full-tree comparison includes Git internals, ignored files, empty directories, links, named streams and recorded metadata. Equal recorded data does not approve a move or deletion.
